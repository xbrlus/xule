Setup Guide

Configure Google OAuth and Xero webhooks to send email notifications to david.tauriello@xbrl.us when a bill is submitted for approval.

01
Create a Google OAuth Client
In Google Cloud Console, go to APIs & Services → Credentials. Create an OAuth 2.0 Client ID of type Web application. Add your app's origin to Authorised JavaScript Origins (e.g. http://localhost:5500). Copy the Client ID — you don't need the client secret for the browser flow.
02
Enable the Gmail API
In the same Google Cloud project, go to APIs & Services → Library and enable the Gmail API. Also add the OAuth scope https://www.googleapis.com/auth/gmail.send to your consent screen.
03
Enter Credentials & Connect Gmail
On the Dashboard tab, paste your Google OAuth Client ID and your Xero Client Secret, then click Save Credentials. A Connect Gmail button will appear — click it to complete the Google OAuth flow and grant the app permission to send email on your behalf.
04
Register Xero Webhook
In your Xero Developer portal, go to your app → Webhooks. Add a new webhook pointing to your server URL (e.g. https://your-domain.com/xero/webhook). Subscribe to the Invoices event type. The webhook key is used for HMAC-SHA256 signature verification.
05
Deploy & Test
Deploy the backend to any Node.js host (Railway, Render, Fly.io, etc.). Use the Dashboard tab to send a test notification and confirm delivery to david.tauriello@xbrl.us. Then submit a real bill in Xero — you'll receive an email within seconds.
✓ The webhook handler only sends emails for bills with type ACCPAY (Accounts Payable) and status SUBMITTED — no noise from other invoice events.
