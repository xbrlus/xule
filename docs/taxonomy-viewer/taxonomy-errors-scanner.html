Invalid Conformance Tests — Taxonomy Errors Scanner

How it works: This page loads each Invalid Conformance Test JSON file in the taxonomy viewer (via the ?file= URL parameter), waits for the model to load and validation to complete, then reads the "Taxonomy Errors" section from the rendered page. Results are formatted as a Markdown table.

Important: This page must be served from the same origin as the taxonomy viewer (xbrlus.github.io/xule-dev/taxonomy-viewer/) for cross-frame access to work. If running locally, both pages must be on the same localhost port.
